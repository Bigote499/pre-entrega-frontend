# Proyecto del curso Front-End JS

## Descripción

Este proyecto es una página web básica desarrollada como parte de un curso de Front-End.  
La página está estructurada con HTML semántico y utiliza las etiquetas `<header>`, `<main>` y `<footer>` para organizar el contenido.  
El objetivo es aprender a crear la estructura básica de una página web y prepararla para futuras mejoras con CSS y JavaScript.

## Contenido

- **Header** con logo y título.
- **Navbar** con enlaces de navegación.
- **Main** con video de presentación y tarjetas de producto/paquete.
- **Footer** con derechos reservados.

## Tecnologías utilizadas

- HTML5
- CSS3 (Flexbox, tipografías externas, gradientes)
- Google Fonts (Roboto y Open Sans)

## Ejercicios aplicados

1. Estructura semántica de la página.
2. Tipografías externas con Google Fonts.
3. Fondo personalizado con degradado.
4. Tarjetas de producto con Flexbox.
5. Estilos básicos de navegación y botones.

## Actualizaciones recientes

- Sección **Reseñas** organizada con **CSS Grid** para cumplir la consigna de diseño responsivo.
- Ajustes de **Media Queries** para que las reseñas se apilen en una sola columna en pantallas pequeñas.
- Mejora visual con `hover` y `transition` en las tarjetas `.card`.
- Separación clara entre **Productos** y **Reseñas** mediante espaciado y estilos adicionales.

## Cómo visualizar

1. Clonar o descargar el repositorio.
2. Abrir el archivo `index.html` en un navegador.
3. Revisar los estilos en `style.css`.
